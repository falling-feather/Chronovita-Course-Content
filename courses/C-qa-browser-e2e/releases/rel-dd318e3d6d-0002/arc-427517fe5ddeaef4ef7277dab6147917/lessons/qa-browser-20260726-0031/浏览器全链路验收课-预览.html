全链路验收说明

本课是浏览器端到端验收用的隔离技术样板，包含 加粗文本 与普通正文，不属于正式历史课程。

第二段验证 标红文本、封存关键词以及多段正文能够进入预览和结构化归档。

第三段记录本次流程只验证草稿、审校、封存、发布和 GitHub 投稿，不提供任何正式史实结论。

关键词

  • 草稿：教师可反复保存和继续修改的内容状态。
  • 审校：对内容结构和来源表达进行检查的过程。
  • 封存：将通过审校的内容生成不可变版本。
  • 发布：让课程服务读取指定封存版本。
  • 归档：将发布版本打包并提交内容历史库。
